# Orbit Zero — Space Adventure Game

A browser-based interactive space shooter built with **HTML, CSS and JavaScript**.

## How to run
1. Download or clone this project.
2. Open the `space_adventure_game` folder in Visual Studio Code.
3. Open `index.html` in a browser (Chrome, Edge or Firefox). You can also use the VS Code Live Server extension.
4. Select a difficulty and click **Start Mission**.

## Controls
- Arrow keys (or WASD): move the spaceship.
- Spacebar: shoot.
- P: pause or resume.

## Features
- Welcome screen and instructions.
- Easy, Medium and Hard difficulty levels.
- Keyboard-controlled player spaceship.
- Automatically moving enemy spaceships.
- Shooting and bullet/enemy collision detection.
- Player/enemy collision detection.
- Score, shields (lives) and level display.
- Game Over screen and Play Again option.
- Best score saved in the browser using localStorage.
- Responsive layout for desktop and mobile screens.
